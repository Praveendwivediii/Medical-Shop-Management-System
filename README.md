# 💊 Medical Shop Management System

A console-based Medical Shop Management System developed in C++.
The project provides basic medicine inventory management, validation,
search, updating, deletion and billing functionality.

## 📌 Features

- Login authentication
- Password masking using `*`
- Medicine type selection
- Add medicine
- Display all medicines
- Search medicine
- Update medicine
- Delete medicine
- Sell medicine
- Billing system
- File-based data storage
- Medicine name validation
- Company name validation
- Batch validation
- Expiry validation
- Price validation
- Quantity validation

## 💊 Medicine Types

The system supports:

1. Syrup
2. Tablet
3. Capsule
4. Syringe
5. Injection
6. Drops
7. Cream
8. Ointment
9. Inhaler
10. Powder
11. Gel
12. Suppository
13. Lozenge
14. Spray
15. Other

## 🛠️ Technologies Used

- C++
- File Handling
- Object-Oriented Programming
- Console Application
- Dev-C++ 5.11

## 💻 System Requirements

- Windows
- Dev-C++ 5.11 or compatible C++ compiler
- C++ compiler supporting `conio.h`

## ▶️ How to Run

1. Download or clone this repository.
2. Open `src/MedicalShop.cpp` in Dev-C++.
3. Compile the program.
4. Run the program.
5. Login using the demo credentials.
